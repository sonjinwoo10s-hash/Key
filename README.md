# كيبورد برو (Keyboard Pro Replica - Android)

مشروع أندرويد كامل (Kotlin + Jetpack Compose + Custom Zero-Latency Canvas IME) يحاكي واجهة وميزات تطبيق **كيبورد برو** مع ربط مباشر بـ **Google Gemini API**.

## المميزات المدمجة:
1. **محرك كتابة فائق السرعة (`FastKeyboardCanvasView`):** مرسوم بالكامل على `Canvas` بدون أي تأخير (Zero Latency)، يدعم اللمس المتعدد السريع (Fast Rollover)، تحريك المؤشر بالسحب على المسطرة، والمسح المتسارع.
2. **ربط فعلي بـ Gemini API (`GeminiAiClient`):**
   - تصحيح إملائي ونحوي فوري للنص المكتوب.
   - إعادة صياغة الجمل بأسلوب احترافي.
   - ترجمة فورية داخل الكيبورد (عربي ⇄ إنجليزي).
   - اقتراح ردود ذكية وتخصيص أسلوب المساعد (`يتعلم منك`).
3. **لوحات الكيبورد المدمجة:**
   - مضاعف الإيموجي السريع (`+1`, `+3`, `+5`, `+7`).
   - الحافظة المقسمة (الأحدث والمثبتة 📌).
   - لوحة اللمس (Trackpad) للتحكم في المؤشر والنسخ واللصق.
   - شريط الزخرفة الفورية (ممدود، مشكول، ملكي، إنجليزي مزخرف).
4. **بناء تلقائي عبر GitHub Actions:** ارفع الملفات إلى مستودع GitHub وسيقوم ملف `.github/workflows/android-build.yml` ببناء ملف `app-debug.apk` تلقائياً.
